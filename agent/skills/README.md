# HoldSpeak repository skills

These skills guide coding agents working on this repository. They do not
register model tools or create runtime Workbench skills. Each `SKILL.md` has
portable name/description frontmatter and repository-relative inspection paths.
Use the relevant skill after reading the current repository and lane charter.

The active owner request overrides standing workflow rules. A skill does not
grant permission to publish, message others, use live credentials or alter the
owner’s application data. Tests run with isolated HOME.
