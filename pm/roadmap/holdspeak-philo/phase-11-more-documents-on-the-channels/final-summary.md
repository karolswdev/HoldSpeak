## Laws learned

- **Disk fills when two full suites run at once.** Serialize the machine's full suites, with quiet trees and isolated HOMEs. #710 discarded an ENOSPC run before its recorded rerun; this close's dispatch reserves the machine for Muad'Dib's current suite ([#710 merge record](https://github.com/karolswdev/HoldSpeak/pull/710#issuecomment-5916724312)). Clean only the scratch space the lane owns.
- **Never symlink node_modules into a worktree.** The `uv` build hook can follow the link and `npm ci` can wipe the target install. Give the worktree its own install (`docs/internal/project-rooms/HANDOVER-MUADDIB-XXVII.md:27`). Preserving a venv executable path is a separate lesson; resolving it can lose the venv (`lane-06-astra.md:46`).
- **Run ALL the Documentation Navigation commands.** A passing link checker misses API, boundary and graph drift. Run all twelve in `.github/workflows/test.yml:26-38`; story 07 found and repaired API-reference drift this way (`lane-07-muaddib.md:19`).
- **Never rewrite a guard to match a deletion.** Restore the owner's discovery phrases, exact body comparison, API/graph identities and shared actuator coverage. A lawful retirement has a named refusal or a declared scope change; a green weakened fence is not proof (`checks/story-01-built-muaddib-r1.md`; `checks/story-02-built-muaddib-r1.md`).
- **Change words and their legitimate fences together.** Distinguish a stale September assertion from a deleted user task. Correct source anchors with the source move, never relax the anchor guard (#715; `lane-06-astra.md`).
- **A double must match the field the check reads.** Prove size and limit through producer, route and face. Mint documents and missing-key states through the real path; pin Slack FAILED and UNKNOWN reasons and mutate the edge to show rejection.
- **The receipt must survive every branch the click leaves.** Key reads and actions by document identity, reject late answers, and assert the same receipt across close, pick, remount and last Ack. Well presence alone proves none of this.
- **Run the actual atlas.** Keep each case/width observation. State optional triggers and presence checks. C4 is a control, operation capability absence is blocked, and a failed rig boot is instrument failure; none should be renamed to improve the red/green story.
- **A narrow screenshot is not a narrow press.** Exercise the 393 transition and read its operation. Repair proof on a scratch target; do not repeat real public sends for better evidence (`checks/story-07-built-astra-r1.md`; `evidence-story-07.md:7`).
- **No internal ID in sent text.** Read the far side, not only the preview. Keep authorized file-name suffixes separate from message content; preserve exact bytes.
- **No blanket restore loop.** Restore only explicit tracked ` M` paths when restoration is required; never touch `??` shots. This docs lane needed no restoration. Keep test output in scratch unless capturing authorized story evidence.
- **Read TWO-BRAINS in each fresh context.** Check new scope before briefing. A dispatched Astra lane leaves its draft for Muad'Dib; it does not manufacture his check. The owner waived retroactive ceremony, not future cooperation.
