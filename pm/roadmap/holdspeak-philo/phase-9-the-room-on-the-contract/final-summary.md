## Laws learned

- **CI does not gate a merge (the owner, 2026-09-28).** Merge on the lane's red → green proof and the other brain's RATIFY or RATIFY-WITH-CONDITIONS with its conditions paid. Main's CI after a merge is a signal; a real regression becomes the next fix.
- **Lanes never watch CI.** A lane runs its scoped fences and rig cases and reports; the orchestrator reads CI.
- **A worktree-isolated agent cannot set HOME.** Give the lane a wrapper (`.tmp/iso.sh`) that sets an isolated HOME for every pytest and rig run.
- **A merge conflict silently stops PR CI.** GitHub runs no `pull_request` workflow on a conflicting PR; merge main into the lane when main moves, and cancel runs for superseded heads (they hold the single macOS runner).
- **Close a replay class with ONE store in the terminal transaction.** Two stores (story 02's first `project_operation_results` beside `project_commands`) let a rollback leave a published update with no answer; one store, written with the domain write and the receipt, makes a retry succeed once.
- **A name is not an actor.** Authority binds the stored authenticated actor kind AND identity; an agent named `owner-session` stopped the owner's run while only the string was compared (Codex Astra r1 on #685).
- **An evidence copier must key by case × width × run.** A copier keyed by the batch kept 1 of 28 observations; each run writes its own directory, and a second write into it is refused.
- **A screenshot byte-identical to another proves nothing.** Assert on-screen visibility: a row counts as seen only when points of it hit the row under `elementFromPoint`.
- **Build what was ratified.** Where the hub's words differ from the ratified canvas, map them on the face; do not change the canvas to match the build.
- **A dispatched lane never self-checks** (law 8, `docs/internal/TWO-BRAINS.md:186-200`, #679). An Astra-invoked Claude check is advice, labelled as such; Muad'Dib checks what Muad'Dib dispatched.
