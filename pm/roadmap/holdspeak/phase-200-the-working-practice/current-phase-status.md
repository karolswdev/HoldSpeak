## Goal

Make HoldSpeak a dependable daily assistant for an architect or technical lead.
Carry one Project from intent and preparation through capture, decisions, commitments, supervised work, and bounded unattended results.
Prove source fidelity, recoverability, and net usefulness with real work.

## Scope

- In: known runtime, clean release path, physical voice proof, source support, coverage, daily Project workflows, three recipes, repeatable Interview setup.
- In: one supervised worker, result verification, durable scheduling, selected always-on deployment, credential lifecycle, owner pilot, release and recovery.
- Out: new hosted service, active-active database, general workflow engine, unrestricted crews, broad connector expansion, portfolio administration, new native parity.
- Out: changing the Constitution or Control mode defaults through this roadmap.

See the [charter](README.md), [baseline](BASELINE.md), and [contracts](CONTRACTS.md).
