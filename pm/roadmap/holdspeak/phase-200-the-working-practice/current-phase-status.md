# Phase 200: The Working Practice

**Last updated:** 2026-09-05, roadmap creation.
**Status:** planning. Forty stories defined; zero implementation stories completed.
**Product owner:** Karol.
**Delivery owner:** unassigned until implementation starts.

## Goal

Make HoldSpeak a dependable daily assistant for an architect or technical lead.
Carry one Project from intent and preparation through capture, decisions, commitments, supervised work, and bounded unattended results.
Prove source fidelity, recoverability, and net usefulness with real work.

## Scope

- In: known runtime, clean release path, physical voice proof, source support, coverage, daily Project workflows, three recipes, repeatable Interview setup.
- In: one supervised worker, result verification, durable scheduling, selected always-on deployment, credential lifecycle, owner pilot, release and recovery.
- Out: new hosted service, active-active database, general workflow engine, unrestricted crews, broad connector expansion, portfolio administration, new native parity.
- Out: changing the Constitution or Control mode defaults through this roadmap.

See the [charter](README.md), [baseline](BASELINE.md), and [contracts](CONTRACTS.md).

## Exit criteria (evidence required)

- [ ] **G0: Known and recoverable installation.** Runtime identity, isolated checks, cold first value, physical voice, and restore are proven. Evidence: stories 01, 02, 03, 04, 05.
- [ ] **G1: Trustworthy daily Project work.** Claim support, coverage, real-model evaluation, daily flows, and the two-day owner sequence pass. Evidence: stories 06, 07, 08, 09, 10, 11, 12, 13, 14, 15, 16.
- [ ] **G2: Configurable working practice.** Three recipes, replay-safe setup, revisit, one actual scheduled brief, and the R1 pilot pass. Evidence: stories 17, 18, 19, 20, 21, 22, 23.
- [ ] **G3: Supervised assignments.** One adapter, immutable work contracts, verification, intervention, recovery, and five useful tasks pass. Evidence: stories 24, 25, 26, 27, 28, 29, 30.
- [ ] **G4: Bounded unattended execution.** Host and credential recovery, durable triggers, bounded retry, two recipes, and real occurrences pass. Evidence: stories 31, 32, 33, 34, 35, 36.
- [ ] **G5: Adopted release.** Outcome review, packaged candidate, recovery guides, cold rehearsal, and final evidence pass. Evidence: stories 37, 38, 39, 40.
- [ ] Every required story has actual verification and a paired evidence file.
- [ ] Required release checks pass on the exact packaged candidate.
- [ ] No unresolved critical fabrication, unauthorized effect, silent data loss, false completion, or unexplained duplicate remains.
- [ ] Owner acceptance and the retained follow-on obligations are recorded.
- [ ] Final summary and release claims match demonstrated outcomes.

| Forty stories become one large merge | Medium | One scoped story per PR and staged release gates | Multiple unfinished foundations share an unreviewable diff |
