## The thesis (the bar)

The phase's exit proof. Open every program on the live desk,
screenshot every surface at both viewports, and prove every room
speaks one language. The bar: **no surface on the desk reads SaaS;
the whole OS answers the CD-ROM-2004 question with one voice.** This
is the walk the owner sits on.

## Method (phase canon)

1. Walk every program and system chrome surface on the real hub via
   live Playwright, 1440 and 393.
2. File the full screenshot set as evidence assets.
3. Any surface that breaks the language gets fixed in this story or
   filed as a named follow-up in the backlog — no silent passes.
4. Update the phase status, README cadence lines, and any canon doc
   the phase touched; stage the closeout for the owner sitting.

## Test plan

- A complete screenshot set exists in evidence assets: every program,
  every pane, both viewports.
- Zero `backdrop-filter`, zero off-kit radii, zero Inter chrome
  labels findable in the walked surfaces.
- The phase status story table shows 01–09 done before this flips.
- Owner sitting scheduled with the walk set as the exhibit.
