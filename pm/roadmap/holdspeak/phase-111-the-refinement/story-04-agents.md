## The thesis (the bar)

The Agents/Companion program — agent list, persona detail, session
inspector, coder steering pullout — is the operator's crew roster.
The bar: **it reads as a systems console for the crew (roster rows,
sunken session logs, beveled steering controls), not a directory of
profile cards.** Workbench 2.0 grammar, dark 2004-techy render.

## Method (phase canon)

1. **Audit.** An agent walks the list, persona detail, session
   inspector, and steering pullout; files every SaaS-ism.
2. **Rethink.** Propose the native interior — layout, density,
   control style, typography — against the phase question.
3. **Implement** in `web/src`.
4. **Prove** with live screenshots on the real desk, 1440 and 393.

## Test plan

- The agent list is a dense roster ledger, not avatar cards.
- Session inspector logs render in a sunken mono well.
- The coder steering pullout uses the shared gadget kit and reads as
  part of the program, not an overlay from another product.
- Screenshot walk at both viewports, no overflow.
