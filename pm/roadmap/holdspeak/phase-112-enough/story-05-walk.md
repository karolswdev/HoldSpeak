## The thesis (the bar)

The phase's exit proof and the owner's sitting exhibit, walked as
one unbroken session on a genuinely fresh HOME — the exact
experience the owner asked for, end to end, nothing staged that a
new machine would not have. The bar: **fresh boot → the architect's
desk is there → set the one dial → hold TALK in Speak → the text
lands with a receipt → reset-to-seed returns the desk — and every
beat photographed at 1440+393 including the refusal legs.**

## Method

1. Boot the hub under an isolated fresh HOME (the product's own
   isolation lever); no seeds pre-applied by the rig.
2. Walk the beats in owner order: first-boot desk impression; open
   the ADR template; Prefs → the models dial → point it at the real
   LAN endpoint (real metal, standing rule); Speak → hold → release
   → the text lands in a real focused app AND a real agent pane;
   the latency receipt read aloud; one refusal leg per surface
   (unreachable endpoint, unresolved focus); then reset-to-seed on
   a deliberately dirtied desk.
3. The one-paragraph README read against the walked reality — any
   sentence the walk contradicts is fixed in-story or named.
4. Census sweep: the HS-112-01 grep guards green; violations found
   mid-walk fixed on the spot if small, chartered by name if not.
5. `final-summary.md` — the sitting brief: shots, the named debt
   from 01-03, the held questions.
