# Glossary

Use these meanings when you read HoldSpeak guides. Capitalized names identify
product records, modes, or controls.

| Term | Meaning |
| --- | --- |
| agent | A launched coding-agent session or other worker path, depending on context. It is distinct from a persona and from a CLI used only as an inference engine. |
| Agent persona | Saved instructions for a specialist conversation or handoff. A persona is not a live agent and does not grant tool authority. |
| Ask | The Desk question surface. It shares one window and one saved conversation with Thread. |
| Ask AI | The Go/Dock application entry that opens the window labelled **Ask**. |
| Artifact | A saved output record with information about its source or creator. |
| arrival | The former name for the Desk home state. The active application label is **Today**. |
| assignment | A model or engine selection for a capability or job. |
| automation | Work started by a configured trigger and executed through a supported path. A suggestion is not an automation. |
| Automations | The product surface for watch and reaction configuration outside Project-scoped Watches. |
| About | Records selected as the retrieval starting point for Ask. About is not a blanket access boundary. |
| Cadence | A system that reviews unresolved work and prepares next actions. Its background loop is off by default. |
| cadence | A desired repetition frequency. It does not configure the Cadence system by itself. |
| capability | A registered kind of work with model and execution requirements. |
| Chair | The current Desk home view. The old spatial Floor is parked. |
| Calls | The Desk application for configured phone-number calls, passphrase and caller rules, and the optional Line adapter. |
| Coder session | A live coding-agent session that HoldSpeak can launch, observe, or steer through supported controls. |
| CLI engine | An installed command-line route used for model inference. It is not automatically a coding-agent session. |
| Accounts | The Settings section for service accounts and connections. |
| Archive | The Desk window for parked or deleted presentation records. It does not erase the source record. |
| connector | A component that obtains context from a configured source. Its permissions and data boundary depend on that source. |
| Control mode | A Secure, Normal, or YOLO policy preset for eligible operations. |
| correction | A stored dictation rule. A text correction changes heard text. A routing correction changes a block or delivery target. |
| decision record | A durable record of a decision and available rationale. It does not establish organizational acceptance by itself. |
| Desk | HoldSpeak's web operating surface for records, context, tools, and results. |
| dictation journal | One row per dictation run, with transcript, delivered text, route, latency, and corrections that fired. |
| dictation pipeline | Stages that route or transform dictated text before delivery. |
| egress | Transfer of data outside the current machine or execution boundary. |
| engine | A model runtime, endpoint, model option, or supported CLI route shown in Settings. |
| Engines | The Settings section for model routes and capability assignments. |
| Everyday context | Editable starter prompts that you explicitly attach as AI context. |
| Floor | The former spatial Desk view. It is parked. Use Chair and Desk windows. |
| grant | Bounded authority for an operation, destination, and scope, with expiry or use limits. |
| grounding | Use of selected source records as context for a model result. A source reference does not prove that the result is correct. |
| Heartbeat | An unattended sweep configured through Rhythm. It is distinct from Cadence. |
| hub | The HoldSpeak runtime and data host used by the web Desk and configured clients. |
| inference | A model execution that produces a result from input. |
| Interview | Thread mode for repeatable context and suggestions. The Note Workbench also has a separate Interview pane. |
| Keep as note | A Thread command that saves a reply as a Note. It is different from **Keep idea**, which records a suggestion choice. |
| Learned | The Speak wing that lists stored corrections and their applied counts. |
| MCP | Model Context Protocol. Clients discover and call exposed tools and read resources through it. |
| Memory | The Desk app for standing pages, recall, and search across retained work. |
| Model Library | A service that records model availability, deployment information, and readiness. |
| Note | An editable text record. The current UI calls it Note. |
| Needs you | The Desk drawer for held decisions and other work that requires owner attention. |
| People | The protected surface for confidential relationship records and permitted shared intent. |
| Phone | The Desk Phone wing and service contract. A delivered paired-phone app is not part of the current repository; configured Calls number transport is separate. |
| Places | The former wallpaper picker name. Use Settings > Desk > Wallpaper. |
| Project | A record that groups an outcome, selected sources, and related work. |
| Project Room | The working surface for one Project, its sources, changes, decisions, and scoped automation controls. |
| Project update run | A Project-scoped operation that prepares an update from Project evidence. It is narrower than a whole-Desk Ask. |
| Programs | A goal cut into steps. The Program service tracks steps, checkpoints, handoffs, control level, and owner decisions. It is different from the read-only prepared-procedure catalogue. |
| proposal | A candidate action or decision with its own review, authority, and execution states. |
| Reach | Remote MCP transport with scoped credentials. |
| receipt | An execution record that identifies an operation, its boundary, and result. |
| References | The active Ask answer section that lists cited source records. It is evidence to inspect, not proof that an answer is correct. |
| Resourceful | HoldSpeak's bounded overnight maintenance capability. |
| Notices | The active Settings section for notifications, quiet hours, the daily brief, nudges, and Heartbeat controls. |
| Rhythm | A retained service/configuration name. The active Settings section is **Notices**. |
| Settle in | A temporary Desk view with reduced navigation controls. |
| sidecar | A local MCP process that accesses HoldSpeak services without hosting the web runtime. |
| Speak | The voice-typing window. |
| Steward | A Project component that evaluates observed work and produces supported results under its configured policy. |
| suggestion | An Interview idea with a basis, feasibility, and recorded user choice. It is distinct from an executed action. |
| sweep | One Heartbeat evaluation pass. |
| Thought | A former domain and interface term for a Note being refined. The current UI uses Note. |
| Thread | A saved Ask conversation with turns, references, message parts, receipts, and applicable tools. |
| Today | The active Desk home application for current work, Notes, Meetings, and **Needs you**. |
| tool | A named callable operation. Its existence does not grant execution authority. |
| Watch | A Project-scoped configuration that observes a source population and evaluates conditions. |
| Wallpaper | The Desk atmosphere selected in Settings > Desk > Wallpaper. |
| Workbench | A Note refinement surface or configured automation destination, depending on context. Read the current control label. |
| Zone | A Desk container for filed objects. |
| Line | The optional HoldSpeak phone adapter/node. It can use a SIP address or provider number and sends text turns through the hub; it is not the paired Phone app. |
