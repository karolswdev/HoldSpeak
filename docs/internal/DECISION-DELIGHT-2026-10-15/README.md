## Changes

no longer opens a second full copy in the preview. Existing prepared work,
running/history/refusal facts and failed-read Retry remain discoverable.
Held commands open the well and prevent Hide; Edit/Back keep the existing
unmount boundary and per-document command store. Other document hosts keep
their existing behavior. Ordinary decision previews refresh with accepted
stored-field changes; prepared previews keep their frozen payload.

Done waits for the real decision writer. A refusal keeps the editor and its
fields, with the existing global exact-value Retry plus a named local failure.
Typing during a pending write is allowed; acceptance of that older submission
does not close or overwrite the newer draft. Pending controls use the existing
working chip and consistent disabled state. The independent source review
found and closed one enabled status Retry that the pending writer rejected.

The shared resize divider uses its highest participant's z rank. A higher
unrelated window covers both its paint and pointer target. Exposed drag and
keyboard behavior use the existing geometry and persistence handlers.
