Canvas for AgentWords. One library component draws every word an agent wrote. The text is the owner's shot (08-lane-asks-1440.png), word for word. Kept: bold, italic, inline code, code blocks with a language token, numbered and bulleted lists (one level deep), headings as a bold line, paragraphs and line breaks. Not kept: HTML (shown as text), links as a press target (the link text, then the address as plain text), images (the alt text in brackets). Long names break at / _ - . so nothing leaves the frame at 393. Compact: one line (or two in a Needs row), marks kept, blocks joined with " · ", the cut at a whole word with "…".
