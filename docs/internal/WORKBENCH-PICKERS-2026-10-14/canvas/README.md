# Workbench picker direction

This bounded canvas uses the real CycleGadget, library Button and
DeskWindowFrame with sample choices. The displayed popup drawings pick
material and row grammar; production interaction lives in WorkbenchSelect.

Run from the worktree:

```sh
node web/node_modules/vite/bin/vite.js --config docs/internal/WORKBENCH-PICKERS-2026-10-14/canvas/vite.config.mjs
```

URL: `http://127.0.0.1:4481/`.

Provider shows current check, separate active row and unavailable choice.
Language shows a scrolling list. Destination shows a missing current choice
and a long label. Held shows the disabled owner. Narrow rows own 44px.

Root inspected corrected shots at 1440 and 393 and settled the direction
before product implementation. Shots: `.tmp/workbench-pickers/canvas-corrected/canvas-1440.png`
and `.tmp/workbench-pickers/canvas-corrected/canvas-393.png`. The phone shot
shows the upper cases; production boundary/long-label walks belong to root.
This record does not claim owner visual acceptance.
