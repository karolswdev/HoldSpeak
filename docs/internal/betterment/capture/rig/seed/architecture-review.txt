Me: Architecture review. One topic: idempotent retries for payment requests. Jun wrote the options page.
Jun: Option A: the client sends a dedupe key with every payment request, and the gateway rejects a second request with the same key for twenty-four hours. Option B: a dedupe table on our server, keyed on merchant, amount and a time window.
