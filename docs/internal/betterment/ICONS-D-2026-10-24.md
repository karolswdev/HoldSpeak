# Icons D: flat Workbench (2026-10-24)

The owner called the tilted richer family "absolute cringe". The direction
lane drew four families on one canvas
(`canvases/icons-direction-2026-10-24.html`, sources beside it). The owner
picked D: "Yes, I like D." This supersedes the 2026-10-22 construction
(shallow perspective, layered facets) in RICHER-ICONS-2026-10-22.md and
ILLUSTRATED-ICONS-2026-10-22.md. Those documents stay as history. The 47
names, their URLs, their 64/32 sizes, the real state images and smooth
sampling stay.

## The rules

- Front-on flat silhouettes. Two or three flat tones for each material. No
  gradient, perspective, tilt or skew.
- Navy `#263b53` outline, 1.5 units at 64.
- A hard Workbench bevel. A light edge at the top left in the material's
  paper tint and a shade edge at the bottom right in its darker tone. The
  bevel is 2.5 units at 64 (about 2 px at the desk's 48 px), 1 px at 32. At
  20 px there is no bevel, the outline is heavier and the greys are lighter.
  Light comes from the upper left.
- Palette: navy, blue `#477fe0`, teal `#259c96`, violet `#8870cb`, amber
  `#ecaa45`, paper `#f8fbff`, and the grey-blue `#9fb3c8` family for paper
  and metal bodies. One accent for each object.
- Folders: a grey-blue paper back and tab, a sheet, and a coloured front.
  A zone's front wears its colour: Inbox blue, Work teal, Personal violet,
  Reference amber, all other zones blue. A Project is a blue folder with an
  amber pennant (the mark reads at 20 px). Smart and Conductor drawers have
  a paper front with an emblem (a lens, an agent tile).
- Agents are front portrait tiles. Claude Code (amber, a spark), Codex (teal,
  a slit visor) and pi (violet, an antenna) differ by colour and one detail.
  The Agents app wears a blue tile with ear bolts.
- The automation loop is a heavy bevelled band with an arrowhead, not a thin
  stroke, so it reads on the blue title bar.
- Art stays inside x/y 5..58. Sources are self-contained SVG: no fonts, text,
  filters, images or external references. `.detail` marks trim that may
  vanish below 64.

## Zone colour source

A directory carries no paint on the hub. `DirectoryRecord`
(`holdspeak/db/models/__init__.py`) says a zone's paint is per-surface
layout and never canonical. So the hue lives in the web sprite map:
`ZONE_HUES` in `web/src/desk/sprites.ts`, keyed by the packaged zone's stable
seed id (`holdspeak/seeds/fresh-desk.yaml`), never by its name. A renamed
Work stays teal. Every other zone and every Project is blue.
`spriteName("directory", id)` reads it, so every caller of the sprite map
gets the right front.

## Pipeline

- `web/scripts/gen-icons-d.py` is the source of truth. It writes the 51
  sources under `web/design/icons/{world,system,settings}`. `--check`
  compares them with the generator. The 64-unit level is a set of CSS custom
  properties on the SVG root (`--ow`, `--u`, `--nu`, `--lw`). The bevel is
  three uses of the shape: light, shade offset by `--u`, base clipped
  between them. The bevel `<use>` elements carry `.bv` / `.bvn`.
- `web/scripts/gen-illustrated-icons.py` renders each export with the
  `LEVELS` rules for its size. 32 sets a 1 px bevel and a 2.2 outline. 20
  sets no bevel, a 3.0 outline, lines ×1.35 and the lighter grey. The old
  ×1.15 stroke rule is gone. New families: world `20/` and `system/20/`.
  The source/asset check now refuses only a lost name; a new source adds a
  name.
- `web/scripts/gen-sprite-states.py` also derives `_sel`/`_stale` for `20/`.
- New names: `zone-drawer`, `zone-drawer-teal`, `zone-drawer-violet`,
  `zone-drawer-amber` (`ZONE_SPRITES`). `directory` now wears `zone-drawer`
  and no longer shares `project-drawer` with a Project.
- New size: `SpriteSize` 20. `glyphSprite(url)` maps a world sprite (any
  size or state) to `20/` and a system sprite to `system/20/`. The dense
  ObjectList row and the window title glyph read it. The Dock keeps 32.
- Title bar: the 16 px glyph sits on a 22 px paper chip with a 1 px soft rule
  on every plane, set once in `window-chrome.css` (`.desk-window-icon`). The
  title slot in `DeskWindow.tsx` swaps the host's image for its 20 px file;
  the Dock seat keeps the host's own image.

Counts: 117 base exports (23 world × 3 sizes, 20 system × 2, 8 Settings).
255 active PNGs with states (69 each in the root, `32/` and `20/`; 20 + 20
system; 8 Settings).
