Each hue reads 4.5:1 or more on the paper, so it may carry a word (a person named in a note is already this teal: --wb-person-ink, Note canvas A). The hue is used in exactly four places: the glyph's seat, the row's hover wash, the selection wash when the list is not focused, and the 3 px rule of a peek or margin card. The rules, as kit doc comments

/** DELIGHT (2026-10-27) — the kind hue. Each object kind owns ONE hue
 *  (--kind-meeting, --kind-project, --kind-person, --kind-decision,
 *  --kind-note, --kind-pr, --kind-action, --kind-agent), taken from its
 *  D object. The hue is used in four places only: the 20 px glyph's 24 px
 *  seat (13 % wash, 22 % rule), the row's hover wash (8 %), the selection
 *  wash of a list that does not hold focus (14 % + a 3 px kind rule), and
 *  the 3 px rule of a peek or margin card. Never on a Button, never as a
 *  text block. A focused list's selection stays the selection blue. */

/** DELIGHT — motion. Six named moments: the save pulse, the task tick,
 *  the body's first paint, found rows arriving, the Done settle, the
 *  Record breath. Each runs once (the breath runs while recording), is at
 *  most 200 ms (the pulse's glow 600 ms on a lamp, not a control), moves
 *  opacity, colour or a lamp's box-shadow only, never a measured box, and
 *  is instant under prefers-reduced-motion. No bounce, no overshoot. */

/** DELIGHT — an empty state is an object: the kind's 64 px D object on
 *  an 88 px halo, one line in the display face, one verb (the window's
 *  making verb, secondary form). SurfaceState empty with emptyImage +
 *  emptyKind. */

/** DELIGHT — a live lamp glows: a lit dot (ok, info, ask) in a status bar
 *  or a DotWord wears a 3 px ring in its tone. Idle and fail do not glow. */
