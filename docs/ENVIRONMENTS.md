# Places

Choose the Desk atmosphere in **Settings > Wallpaper**. Use **Hide the menus**
when you want fewer navigation controls around open work.

## Change places

1. Open **Settings > Wallpaper**.
2. Select an atmosphere with its radio control.
3. Return to the Desk.

The older **Change places** surface is an alias for the Wallpaper module. Its
**All places**, **Favorites**, and **Hide the menus** controls remain when that
surface is available. There is one Desk. Changing the atmosphere does not move
records or change the hub's Desk windows.

## Available places

**Quiet Desk** is the default. Select another atmosphere for a live scene.

| Place | Scene |
| --- | --- |
| Rainy City | Rain, neon signs, steam, and street reflections |
| Lantern Garden | Wet stone paths, plants, drizzle, and lanterns |
| In Jupiter's orbit | Cloud bands, moons, and stars |
| In Mars' orbit | A Mars orbit scene |
| In Saturn's orbit | A Saturn orbit scene |
| Quiet Desk | A still background without room sound |
| After-Hours Radio | A walnut radio booth with a rainy skyline |
| Midnight Archive | Card cabinets, green lamps, and dust |
| Night Train | A green train compartment with passing trees and station lights |
| Deep-Sea Station | An observation port with marine life and sonar |
| Storm Greenhouse | Iron rafters, terracotta pots, rain, and cloud light |
| Last Laundromat | Mint tiles, moving drums, and fluorescent light |

The scenes are decorative. Capture indicators can respond to existing recorder
state. The scenes do not acquire a microphone or start product work.

### In Jupiter's orbit

Open **Settings > Wallpaper** and select **In Jupiter's orbit**. The scene uses
local maps and its own scene timing. Its sizes and times do not show current
positions in space.

## Save favorites

When the picker shows a star, select it to add or remove a favorite. Use
**Favorites** to filter the list. The star changes favorite state. It does not
select the atmosphere.

The selected atmosphere, favorites, animation preference, and sound preference
are local to this browser. They survive a reload in that browser. They do not
become shared hub settings.

## Control motion and sound

Use **Motion** in Wallpaper settings to pause or resume animation. The
operating system reduced-motion preference takes precedence. Hidden tabs pause
the scenes.

Room sound is off by default. When enabled, HoldSpeak generates quiet room
sound locally. It reduces sound while the browser microphone is open or the hub
reports recording. It suspends sound in a hidden tab. **Quiet Desk** has no
room sound.

## Settle in

1. Select **Hide the menus** in the dock or Desk menu.
2. Continue work in the open windows.
3. Select **Back to Desk** to restore navigation controls.

**Command/Ctrl+Shift+F** toggles Settle in. The first **Escape** restores the
Desk without closing the focused window or draft. The recorder state and
record control remain available.

Settle in is a temporary browser view state. It does not change recording,
enable sound, or save a new window layout.

## Troubleshooting

| Problem | Action |
| --- | --- |
| An animated scene stays still | Check **Motion** and the operating system reduced-motion setting. |
| There is no room sound | Enable sound in Wallpaper. Check whether recording or a hidden tab suspended it. |
| Favorites are absent in another browser | Set favorites in that browser. The preference does not synchronize through the hub. |
| Navigation controls are absent | Select **Back to Desk** or press **Escape**. |
| A scene is distracting or slow | Select **Quiet Desk** or pause animation. |
